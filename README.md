# API Testing — REST API

Учебный QA-проект по тестированию REST API с использованием Postman.

## Цель проекта

Проверка корректности работы API, обработки валидных и невалидных запросов, HTTP status codes и структуры ответов.

## Что тестировалось

- GET — получение данных
- POST — создание данных
- PUT / PATCH — изменение данных
- DELETE — удаление данных
- HTTP status codes
- Response body
- JSON structure
- Валидация входных данных
- Обработка некорректных запросов

## Артефакты тестирования

- Checklist
- Test Cases
- Postman Collection
- Bug Reports
- Evidence

## Использованные подходы

- API Testing
- Functional Testing
- Positive / Negative Testing
- Validation Testing
- Boundary Value Analysis
- Equivalence Partitioning
- Status Code Validation
- Response Validation

## Tools

- Postman
- Git / GitHub

## API

The project uses a public REST API for testing purposes.
